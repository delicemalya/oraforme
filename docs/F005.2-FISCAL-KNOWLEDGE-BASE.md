---

## LÉGENDE CONFIANCE DES DONNÉES

```
★★★  HAUTE      — Texte légal officiel analysé (LF promulguée, CGI officiel, DGI nationale)
★★☆  MOYENNE    — Source secondaire fiable (DGI site web, cabinet comptable agréé)
★☆☆  À VÉRIFIER — Estimation depuis textes non récents — NE PAS CODER sans vérification
```

**Règle certificateur :** toute entrée ★☆☆ est interdite dans FM-1 sans validation source officielle.

---

## SCHÉMA FKB — Structure d'une entrée

Chaque entrée fiscale respecte ce schéma :

```
FKB-[CC]-[TAX]-[NNN]
  pays        : code ISO 2 lettres
  impot       : TVA | CA | IRPP | CNSS | IS | PAT | TXL | RAS | AUT
  confiance   : ★★★ | ★★☆ | ★☆☆
  source      : référence légale exacte
  version     : date d'entrée en vigueur
  ─────────────────────────────────────
  définition  : [description courte]
  formule     : [formule mathématique]
  paramètres  : [liste des variables]
  entrées     : [données requises]
  sorties     : [montants produits]
  événements  : [FiscalEvent(s) déclencheur(s)]
  écritures   : [journal_entries à créer]
  déclaration : [formulaire + table DB]
  paiement    : [compte + délai]
  contrôles   : [règles de validation]
  cas_part    : [exceptions et cas limites]
```

### FKB-CG-TVA-001 — Taxe sur la Valeur Ajoutée

```
confiance   : ★★★
source      : CGI Congo Art. 199-255 + LF 2026 Art. 14
version     : 2026-01-01

définition  : Impôt indirect sur la consommation, collecté par les assujettis
              sur leurs ventes et déduit sur leurs achats professionnels.

formule     : TVA_collectée = Σ (HT_vente × 0.18)
              TVA_déductible = Σ (HT_achat × 0.18) [sous conditions]
              TVA_nette = TVA_collectée - TVA_déductible

paramètres  : taux_normal = 0.18 (18%)
              taux_réduit = inexistant au Congo
              taux_zéro   = exportations, certains produits (liste CGI Art. 215)
              seuil_assujettissement = 90,000,000 FCFA CA annuel HT (LF 2026)
              régime      = mensuel

entrées     : montant_ht, pays='CG', date_operation, nature_operation

sorties     : tva_montant, total_ttc, statut_exoneration

événements  : INVOICE_ISSUED      → TVACollecteeEvent
              PURCHASE_RECORDED   → TVADeductibleEvent
              INVOICE_CANCELLED   → TVACollecteeAvoirEvent

écritures   : Sur vente :
                ① DEBIT  411xxx  montant_ttc    (client)
                ② CREDIT 706xxx  montant_ht     (produits)
                ③ CREDIT 4441    montant_tva    (TVA collectée)
              Sur achat :
                ④ DEBIT  60xxxx  montant_ht     (charge)
                ⑤ DEBIT  4445    montant_tva    (TVA déductible)
                ⑥ CREDIT 401xxx  montant_ttc    (fournisseur)
              Sur avoir :
                ① DEBIT  706xxx  montant_ht
                ② DEBIT  4441    montant_tva
                ③ CREDIT 411xxx  montant_ttc

déclaration : Table : declarations_generales
              Formulaire : DGI Congo — Déclaration mensuelle
              Ligne : l1_tva_collectee, l2_tva_deductible, l4_tva_nette
              Source EXCLUSIVE : journal_entries comptes 4441 (crédit), 4445 (débit)
              Délai dépôt : 20 du mois M+1

paiement    : Compte débiteur : 4441 (solde → 0)
              Compte créditeur : 52xxxx (banque)
              Délai : 20 du mois M+1 (même que déclaration)
              Table : enregistré dans declarations_generales.date_paiement

contrôles   : C1 : Σ crédit 4441 = l1 déclaration TVA (tolérance 0 FCFA)
              C2 : date_depot ≤ J+20 mois suivant
              C3 : solde 4441 = 0 après paiement
              C4 : CA HT annuel ≥ 90M → assujetti vérifié

cas_part    : Crédit TVA : si TVA_nette < 0 → report ou remboursement (CGI Art. 244)
              Exportations : taux 0%, TVA déductible récupérable
              Immobilisations : TVA déductible sur compte 4446 (pas 4445)
              TVA sur encaissement : pour les prestations de services Congo
              Prorata : si activités mixtes (taxables + exonérées) → Art. 237
```

### FKB-CG-CA-001 — Centime Additionnel

```
confiance   : ★★★
source      : CGI Congo Art. 256-260 + LF 2026 Art. 15
              "Contribution d'Appui"
version     : 2026-01-01

définition  : Taxe additionnelle perçue sur la TVA collectée.
              S'applique sur la TVA collectée (PAS sur le HT).
              Versée en même temps que la TVA à la DGI.

formule     : CA = TVA_collectée × 0.05

paramètres  : taux = 0.05 (5%)
              base  = TVA_collectée (pas le HT, pas le TTC)
              régime = mensuel (même déclaration que TVA)

entrées     : tva_collectee (montant TVA du mois), pays='CG'

sorties     : montant_ca

événements  : INVOICE_ISSUED → CAEvent (déclenché simultanément à TVACollecteeEvent)
              ⚠️ PAS un événement séparé — sous-calcul du même événement INVOICE_ISSUED

écritures   : Sur vente (en plus des écritures TVA) :
                ④ CREDIT 4441-CA  montant_ca   (CA collecté — compte dédié)
              Le DEBIT 411xxx du montant TTC inclut le CA :
                montant_ttc = HT + TVA + CA

déclaration : Table : declarations_generales
              Formulaire : DGI Congo — même formulaire TVA
              Ligne : l3_tva_centimes = Σ crédit 4441-CA du mois
              Source EXCLUSIVE : journal_entries compte 4441-CA
              ⚠️ JAMAIS l3 = TVA_collectée × 0.05 directement (résout B002)

paiement    : Payé simultanément avec la TVA
              Compte : 4441-CA → 52xxxx (même virement que TVA)

contrôles   : C1 : Σ crédit 4441-CA = l3 déclaration (tolérance 0 FCFA)
              C2 : ratio l3/l1 = 0.05 ± 1% (si écart → vérifier écritures CA)
              C3 : 4441-CA soldé après paiement TVA+CA

cas_part    : CA s'applique UNIQUEMENT au Congo (CG)
              CA ne s'applique PAS à la TVA déductible
              Sur avoirs : CA reversé = CA initial × proportion avoir
              Exportations : CA = 0 (base TVA = 0)
```

### FKB-CG-IRPP-001 — Impôt sur le Revenu des Personnes Physiques

```
confiance   : ★★★
source      : CGI Congo Art. 76-115 + LF 2026 Art. 22-28
version     : 2026-01-01

définition  : Retenue à la source sur les salaires et revenus assimilés.
              L'employeur retient l'IRPP sur le salaire brut du salarié
              et le verse à la DGI avant le 20 du mois suivant.

formule     : base_imposable = salaire_brut - cnss_salarie
              IRPP = Σ (tranche_i × taux_i) pour base_imposable
              net_à_payer = salaire_brut - cnss_salarie - IRPP

paramètres  : abattement_pct = 0 (LF 2026 — abattement forfaitaire supprimé)
              tranches_annuelles :
                0         → 464,000    : 0%
                464,001   → 1,000,000  : 1%
                1,000,001 → 3,000,000  : 10%
                3,000,001 → 8,000,000  : 25%
                8,000,001 → ∞          : 40%
              (pour mensuel : diviser les plafonds par 12)

entrées     : salaire_brut, cnss_salarie, pays='CG', mois, employe_id

sorties     : base_imposable, irpp_mensuel, net_a_payer

événements  : SALARY_PAID (bulletin statut → 'payee') → IRPPEvent

écritures   : Sur bulletin validé :
                ① DEBIT  661-IRPP   irpp       (charge employeur/RAS)
                ② CREDIT 447        irpp       (IRPP à verser DGI)
              Sur paiement DGI :
                ③ DEBIT  447        irpp_total
                ④ CREDIT 52xxxx     irpp_total

déclaration : Table : declarations_generales
              Formulaire : DGI Congo — l8_irpp_salaires
              Source EXCLUSIVE : Σ crédit journal_entries compte 447 (mois)
              Délai dépôt : 20 du mois M+1

paiement    : Compte : 447 → 52xxxx
              Délai : 20 du mois M+1

contrôles   : C1 : Σ crédit 447 journal = l8 déclaration
              C2 : calcul IRPP(brut) cohérent avec bulletin_paie.irpp
              C3 : 447 soldé après paiement DGI
              C4 : base_imposable ≥ 0 (pas de négatif)

cas_part    : SMIG = 70,400 FCFA/mois (LF 2026, arrêté 2025)
              Aucun IRPP si base_imposable ≤ 464,000 FCFA annuel (38,667/mois)
              Avantages en nature : imposables au prix du marché
              13e mois : imposable selon règles CGI Art. 89
              Indemnités de licenciement : exonérées dans certaines limites (CGI Art. 90)
              Allocations familiales CNSS : exonérées d'IRPP
```

### FKB-CG-CNSS-001 — Cotisations Sociales CNSS

```
confiance   : ★★★
source      : Loi n°004-86 du 25/02/1986 (CNSS Congo) + LF 2026 modifications
version     : 2026-01-01

définition  : Cotisations obligatoires au régime de sécurité sociale congolais.
              4 branches : Vieillesse/Invalidité/Décès (VID),
              Accidents du Travail/Maladies Professionnelles (AT/MP),
              Allocations Familiales (AF), TUS (Taxe Unique sur les Salaires).

formule     :
  cnss_salarie  = min(brut, 1,200,000) × 0.04
  vid_patronal  = min(brut, 1,200,000) × 0.08
  af_patronal   = min(brut,   600,000) × 0.1003
  at_patronal   = min(brut,   600,000) × 0.0225
  tus_patronal  = brut_déplafonné    × 0.03
  cnss_patronal = vid_patronal + af_patronal + at_patronal + tus_patronal

paramètres  : TAUX_VID_SALARIE     = 0.04     (4%)
              TAUX_VID_PATRONAL    = 0.08     (8%)
              TAUX_AF_PATRONAL     = 0.1003   (10.03%)
              TAUX_AT_PATRONAL     = 0.0225   (2.25%)
              TAUX_TUS_PATRONAL    = 0.03     (3%)
              PLAFOND_VID          = 1,200,000 FCFA/mois
              PLAFOND_AT_AF        = 600,000  FCFA/mois
              SMIG                 = 70,400   FCFA/mois (LF 2026)

  ⚠️ TUS = 3% PATRONAL UNIQUEMENT sur salaire déplafonné
  ⚠️ TUS FISCALE (4.5% DGI) = ABOLIE par LF 2026 → l9_tus dans décl. DGI = 0

entrées     : salaire_brut, employe_id, mois, pays='CG'

sorties     : cnss_salarie, cnss_patronal, { vid_pat, af_pat, at_pat, tus_pat }

événements  : SALARY_PAID (bulletin statut → 'payee') → CNSSEvent

écritures   : Sur bulletin validé :
                ① DEBIT  661-CNSS-SAL  cnss_salarie   (charge retenue salarié)
                ② DEBIT  661-CNSS-PAT  cnss_patronal  (charge patronale)
                ③ CREDIT 431-CNSS-SAL  cnss_salarie   (CNSS sal. à verser)
                ④ CREDIT 431-CNSS-PAT  cnss_patronal  (CNSS pat. à verser)
              Sur paiement CNSS :
                ⑤ DEBIT  431           total_cnss
                ⑥ CREDIT 52xxxx        total_cnss

déclaration : Table : declarations_cnss + declarations_cnss_lignes
              Formulaire : Déclaration Nominative CNSS Congo
              Source montants : Σ crédit 431-CNSS-SAL + Σ crédit 431-CNSS-PAT
              Source nominatif : bulletins_paie (référence identité, pas recalcul)
              Délai dépôt : 15 du mois M+1

paiement    : Compte : 431 → 52xxxx
              Délai : 15 du mois M+1 (5 jours avant DGI)

contrôles   : C1 : Σ crédit 431 = total déclaration CNSS
              C2 : salaire_brut ≥ SMIG (70,400) pour chaque bulletin
              C3 : plafond VID = 1,200,000 (pas dépassé dans calcul)
              C4 : plafond AT/AF = 600,000 (pas dépassé dans calcul)
              C5 : 431 soldé après paiement

cas_part    : Employé temps partiel : SMIG au prorata des heures
              Stagiaires rémunérés : cotisables si rémunération ≥ SMIG
              Gérants majoritaires SARL : régime spécial (non-salarié)
              Expatriés : cotisables si contrat de travail local
              Conventions bilatérales : détachement possible
```

### FKB-CG-IS-001 — Impôt sur les Sociétés

```
confiance   : ★★★
source      : CGI Congo Art. 1-75 + LF 2026 Art. 2-12
version     : 2026-01-01

définition  : Impôt annuel sur les bénéfices nets réalisés par les sociétés.
              Taux de droit commun : 30%.
              Minimum de perception : 1% du CA HT annuel.
              Provisions trimestrielles obligatoires (acomptes).

formule     : IS_théorique = résultat_fiscal × 0.30
              minimum_perception = CA_HT × 0.01
              IS_dû = max(IS_théorique, minimum_perception)
              acompte_trimestriel = IS_dû_N-1 / 4  (estimation)

paramètres  : taux_normal         = 0.30  (30%)
              minimum_perception  = 0.01  (1% CA HT)
              avances             = 4 acomptes trimestriels (mars, juin, sept, déc)
              écheance_solde      = 30 avril N+1
              taux_secteur_petro  = 0.30  (même taux, régime spécifique)

entrées     : resultat_fiscal, ca_ht_annuel, exercice, pays='CG'

sorties     : is_theorique, minimum_perception, is_du,
              type: 'taux_normal' | 'minimum_perception'

événements  : QUARTER_CLOSED → ISAvanceEvent (× 4 trimestres)
              YEAR_CLOSED    → ISCalculEvent (régularisation annuelle)
              TAX_PAID       → ISPaiementEvent

écritures   : Avances trimestrielles :
                ① DEBIT  695     montant_avance   (IS trimestriel estimé)
                ② CREDIT 441-IS  montant_avance   (IS dû provisoire)
              Régularisation annuelle :
                ③ DEBIT  695     solde_is
                ④ CREDIT 441-IS  solde_is
              Paiement IS :
                ⑤ DEBIT  441-IS  is_total
                ⑥ CREDIT 52xxxx  is_total

déclaration : Table : declarations_is (NOUVELLE TABLE — FM-4)
              Formulaire : Liasse fiscale annuelle DGI Congo
              Source EXCLUSIVE : Σ débit 695 journal_entries (exercice)
              Délai dépôt : 30 avril N+1
              Délai paiement : 30 avril N+1

paiement    : Compte : 441-IS → 52xxxx
              Délai : 30 avril N+1

contrôles   : C1 : IS présent dans taxes_annuelles['CG'] (résout B001)
              C2 : Σ débit 695 = is_du déclaration
              C3 : 4 avances versées avant 31/03, 30/06, 30/09, 31/12
              C4 : 441-IS soldé après paiement
              C5 : résultat_net CR = résultat_avant_is - is_du (pas avant IS)
              C6 : minimum_perception appliqué si résultat déficitaire

cas_part    : Résultat déficitaire : IS = minimum_perception (1% CA HT)
              Report déficit : 3 exercices maximum (CGI Art. 12)
              Sociétés pétrolières : régime spécifique (concession + partage)
              Exonérations zone franche : IS réduit pendant 5-10 ans
              Retenue IS acompte sur marchés publics : 2.5%
```

### FKB-CG-PAT-001 — Patente

```
confiance   : ★★★
source      : CGI Congo Art. 300-340 + LF 2026 Art. 35-45
version     : 2026-01-01

définition  : Impôt professionnel annuel sur le chiffre d'affaires réalisé.
              Calculé selon un barème dégressif par tranche de CA.
              Augmenté de Centimes Additionnels (5%) et de la CAMU (0.5%).

formule     : patente_base = f_barème(ca_annuel - ca_exonéré)
              centimes_add = patente_base × 0.05
              camu         = patente_base × 0.005
              patente_total = max(patente_base + centimes_add + camu, 10,000)
              réduction_pétrolière : patente_base × 0.50 (si société pétrolière)

paramètres  : BARÈME LF 2026 (Art. 122 CGI Congo) :
                CA ≤ 1,000,000          → forfait 10,000 FCFA
                1,000,001 → 20,000,000  → 9.75% sur tranche
                20,000,001 → 40,000,000 → 0.65% sur tranche
                40,000,001 → 100,000,000→ 0.45% sur tranche
                100,000,001 → 300,000,000→ 0.20% sur tranche
                300,000,001 → 500,000,000→ 0.45% sur tranche
                500,000,001 → 1Mrd       → 0.14% sur tranche
                1Mrd+1 → 3Mrd           → 0.135% sur tranche
                3Mrd+1 → 20Mrd          → 0.125% sur tranche
                > 20Mrd                 → 0.045% sur tranche
              TAUX_CA_PATENTE  = 0.05
              TAUX_CAMU        = 0.005
              MINIMUM          = 10,000 FCFA (LF 2026 — était 50,000)
              RÉDUCTION_PÉTR   = 0.50

entrées     : ca_annuel, ca_exonere, est_societe_petroliere, credit_n1

sorties     : patente_base, centimes_additionnels, camu, patente_total

événements  : YEAR_OPENED  → PatenteEcheanceEvent (alerte J-30 avant 31/01)
              DECLARATION_PATENTE_FILED → PatenteJournalEvent

écritures   : Sur déclaration Patente validée :
                ① DEBIT  641        patente_total   (impôts et taxes)
                ② CREDIT 441-PAT    patente_total   (dette patente DGI)
              Sur paiement :
                ③ DEBIT  441-PAT    patente_total
                ④ CREDIT 52xxxx     patente_total

déclaration : Table : declarations_patente
              Formulaire : Déclaration Patente Congo (Sections A, B, C)
              Section C : répartition 12 départements Congo
              Délai dépôt : 31 janvier de l'exercice N

paiement    : Compte : 441-PAT → 52xxxx
              Délai : 31 janvier N

contrôles   : C1 : Σ débit 641 = montant déclaration patente
              C2 : date_depot ≤ 31/01
              C3 : minimum 10,000 FCFA respecté
              C4 : centimes_add = patente_base × 0.05 (±1 FCFA arrondi)

cas_part    : CA exonéré : agriculture, pêche artisanale (liste CGI Art. 305)
              Sociétés pétrolières : réduction 50%
              Première année : patente calculée prorata temporis
              Répartition départements : selon localisation des activités
```

### FKB-CM-TVA-001 — TVA Cameroun

```
confiance   : ★★★
source      : CGI Cameroun Art. 125-200 (confirmé DGI.cm + LF 2026)
version     : 2026-01-01

⚠️ CORRECTION CRITIQUE : taux nominal = 17.5% (pas 19.25%)
   Le chiffre 19.25% = TVA 17.5% + CAC 10% composé → erreur répandue mais fausse
   Source officielle : Article 142 CGI Cameroun "17,5 pour cent (17,5%)"

formule     : TVA = HT × 0.175
              Taux réduit (liste limitative) : HT × 0.10
              Taux zéro (exportations) : HT × 0

paramètres  : taux_normal  = 0.175 (17.5%)
              taux_réduit  = 0.10  (logements sociaux, prêts immobiliers 1ère résidence)
              taux_zéro    = 0     (exportations)
              seuil        = 50,000,000 FCFA CA annuel
              régime       = mensuel
              échéance     = 15 du mois M+1 (pas 20 comme Congo)
              CAC TVA      : NON — le CAC s'applique à l'IS et l'IRPP, pas à la TVA

entrées     : montant_ht, taux_applicable (normal/réduit/zéro), pays='CM'

écritures   : identiques à CG (comptes 4441, 4445) — taux différent

déclaration : Formulaire DGI Cameroun mensuel
              Source EXCLUSIVE : journal_entries 4441 (crédit), 4445 (débit)
              Délai : 15 du mois M+1

cas_part    : Facturation électronique normalisée (FEN) : obligatoire LF 2026
```
