```
  → TVA_[pays]          : calculerTVA(montant_ht, rule)

  ② 4441    C             (TVA collectée)
```

## FDC-001 — Déclaration TVA + CA Mensuelle (Congo)

```
Type               : TVA + CA mensuelle
Table DB           : declarations_generales
Fréquence          : mensuelle
Pays applicables   : CG (avec CA), CM, GA, CI, SN, BJ (sans CA)
Échéance CG        : 20 du mois M+1
Échéance CM        : 15 du mois M+1

Source EXCLUSIVE : journal_entries uniquement

MAPPING LIGNES → COMPTES SYSCOHADA :
  l1_tva_collectee   ← Σ CRÉDIT  comptes IN ('4441','4442')        mois M
  l2_tva_deductible  ← Σ DÉBIT   comptes IN ('4445','4446')        mois M
  l3_tva_centimes    ← Σ CRÉDIT  compte = '4441-CA'                mois M
  l4_tva_nette       ← l1 - l2 (si > 0)
  l5_credit_report   ← Σ DÉBIT   compte '4441' hors période (report)
  l6_tva_a_payer     ← max(l4 + l3, 0)
```
