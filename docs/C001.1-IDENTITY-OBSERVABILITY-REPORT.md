## 1. AUTH LOGS — Couverture des événements

### 1.1 Infrastructure

**Migration** : `supabase/migrations/157_identity_auth_logs.sql`

Table `auth_logs` créée avec :
- Contrainte CHECK sur `event_type` (11 valeurs autorisées)
- Contrainte CHECK sur `device` (desktop/mobile/tablet)
- Contrainte CHECK sur `browser` (chrome/firefox/safari/edge/opera/other)
- Contrainte CHECK sur `provider` (email/google/azure/phone/magic_link)
- Contrainte CHECK sur `duration_ms` (≥ 0)
- 4 index : `(tenant_id, created_at)`, `(ip, event_type, created_at)`, `(user_id, created_at)`, `(event_type, created_at)`
- RLS activée : lecture restreinte aux `owner`/`admin` du tenant ; INSERT bloqué pour tous (service role uniquement)
- Vue `auth_metrics_daily` pour agrégation quotidienne
- Fonction `fn_auth_failed_attempts_last_hour(ip)` — détection brute-force
- Fonction `fn_auth_tenant_summary(tenant_id, since)` — résumé JSON
- Fonction `fn_auth_logs_cleanup()` — rétention 90 jours

## 2. IDENTITY METRICS

**Module** : `lib/identity/auth-metrics.ts`

### Métriques disponibles

| Métrique | Description | Calculée depuis |
|----------|-------------|-----------------|
| `totalLogins` | Connexions réussies | COUNT(LOGIN_SUCCESS) |
| `failedLogins` | Connexions échouées | COUNT(LOGIN_FAILED) |
| `logouts` | Déconnexions | COUNT(LOGOUT) |
| `tokenRefreshes` | Rafraîchissements token | COUNT(TOKEN_REFRESH) |
| `expiredSessions` | Sessions expirées | COUNT(SESSION_EXPIRED) |
| `passwordResets` | Réinitialisations MDP | COUNT(PASSWORD_RESET) |
| `activeUsers` | Utilisateurs uniques | COUNT(DISTINCT user_id ON LOGIN_SUCCESS) |
| `blockedAttempts` | Tentatives bloquées | COUNT(ACCOUNT_LOCKED) |
| `avgAuthDurationMs` | Latence moy. (ms) | AVG(duration_ms ON LOGIN_SUCCESS) |
| `simultaneousSessions` | Sessions concurrent. | COUNT(LOGIN_SUCCESS) sur période |

### Periods disponibles

`1h` · `24h` · `7d` · `30d`

### API

```typescript
// Metrics d'un tenant sur 24h
const m = await getAuthMetrics('tenant-uuid', '24h')

// Métriques globales (superadmin)
const g = await getGlobalAuthMetrics('7d')

// Agrégation pure (sans DB)
const a = aggregateMetrics(rows, '24h')
```

## 3. IDENTITY TRACE

**Module** : `lib/identity/auth-trace.ts`

### Champs de chaque trace

```typescript
interface AuthTrace {
  requestId:  string        // UUID généré par request
  sessionId:  string | null // user.id (proxy jusqu'à implémentation session_id)
  userId:     string | null // Supabase Auth UUID
  tenantId:   string | null // depuis profiles.tenant_id
  ip:         string | null // x-forwarded-for (premier hop)
  device:     string | null // 'desktop'|'mobile'|'tablet'
  browser:    string | null // 'chrome'|'firefox'|'safari'|'edge'|'opera'|'other'
}
```

### Fonctions disponibles

```typescript
// Pour routes API (Next.js Request)
buildTrace(request, { userId, tenantId, sessionId })

// Pour Server Actions sans contexte HTTP
buildServerTrace({ userId, tenantId })
```
